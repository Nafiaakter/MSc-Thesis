## 1. Project overview

This project analyzes coded experimental observations from a study comparing AI-assisted learning with teacher-led instruction for arithmetic tasks. The analysis may include descriptive statistics, group comparisons, pre/post/retention outcomes, effect sizes, and figures.

Only authorized, de-identified research data should be used. Do not include children's names, school identifiers, contact details, or other directly identifying information in this repository.

1. Open `thesis_analysis.ipynb` in Google Colab.
2. Upload the approved, de-identified Excel dataset when prompted, or place it in the documented data location.
3. Confirm that the worksheet name and column names match the dataset.
4. Run the notebook from top to bottom, without skipping cells.
5. Review the printed sample sizes, missing-value checks, descriptive statistics, statistical tests, effect sizes, and plots.
6. Save the outputs and record the date and software/package versions used.

## 5. Data checks and analysis transparency

Before interpreting results, the notebook should:

- check the dataset dimensions and column names;
- check for missing values and duplicate participant codes;
- verify that group labels and score ranges are valid;
- report the number of participants included in each analysis;
- state the statistical test used and why it was selected;
- report test statistics, p-values, effect sizes, and confidence intervals where appropriate;
- document any exclusions, corrections, or deviations from the planned analysis.

If multiple hypotheses are tested, explain whether a multiple-comparison correction (such as Holm correction) was applied.

## 6. Reproducibility

To make results easier to reproduce:

- use a fixed random seed for any simulation or randomized procedure;
- keep data cleaning and analysis steps in the notebook rather than editing results manually;
- label simulated data clearly and never present it as observed participant data;
- generate tables and figures directly from the analysis code;
- keep a record of the dataset version and analysis date;
- rerun the complete notebook before sharing it.

Exact numerical results may vary if the dataset, software versions, or analysis choices change. Document these changes.
